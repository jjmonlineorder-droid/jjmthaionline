JJM THAI — IMAGE REPLACEMENT GUIDE

All website images are stored separately in the assets folder. The HTML references image filenames; it does not contain the image artwork embedded in the page.

HOW TO REPLACE AN IMAGE
1. Open the assets folder.
2. Replace the image file you want to change, keeping the exact same filename and extension.
3. Keep the new image in the assets folder.
4. Re-upload/redeploy the website to Netlify/GitHub to publish the change.
